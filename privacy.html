Privacy Policy

Home Assistant Backup App · Last updated 29 September 2026

This page describes how a small, personal app called "Home Assistant" handles data. The app is operated by Tyler Nolf and is used only by its owner. It is not offered to the public.

What the app does

The app connects the owner's own Home Assistant installation to the owner's own Google Drive account. Its only purpose is to store and retrieve Home Assistant backup files in that Drive account.

Data the app accesses

When the owner authorises the app, it gets access to Google Drive so it can create, read, and delete Home Assistant backup files. It does not access Gmail, Contacts, Calendar, or any other Google service.

How data is used and stored

  • Backup files travel directly between the owner's Home Assistant device and the owner's Google Drive.
  • No data is sent to, or stored on, any server operated by the app's owner.
  • No data is collected, sold, shared with third parties, or used for advertising, analytics, or profiling.
  • Backups are encrypted by Home Assistant before they are uploaded.

Google API Services User Data Policy

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting data

The owner can revoke the app's access at any time from the Google Account permissions page. Backup files can be deleted at any time from Google Drive.

Changes to this policy

If this policy changes, the updated version will be posted on this page with a new date.
