Personal methodology

An AI-automated pre-sales workflow

I got tired of pre-sales busywork eating the hours that should go into building great demos, so I built a system that runs my entire pre-sales motion, from the moment a meeting lands to the demo I walk into.

01

Capture

A scheduled automation logs every customer meeting and attaches its call-recording link, so context is captured the moment it happens and never lost.

02

Aggregate

It pulls account and opportunity intelligence together from across my stack: calendar, CRM, call recordings, and Slack. The full picture assembles itself instead of being stitched by hand.

03

Prep

Each morning an automated briefing surfaces what needs attention and drafts discovery prep, so I walk into every call already informed.

04

Build

The same intelligence seeds the build: a discovery brief and a first-draft demo environment, so I start from a tailored board, app, or agent instead of a blank page.

The result: less time on admin, more time building the thing that actually wins the deal. Find the friction, then build the tool that removes it.
